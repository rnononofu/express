# 初期計画

## 概要
社内配布用のWindowsアプリケーションを作成する
PC起動かアプリ起動でバックグラウンドで常駐できるタイプのアプリを制作したい
Windowsに通知を送信して動作状況を確認したい

### 技術スタック

#### バックエンド
- Python 3.12
- uv (パッケージ管理・実行)
- FastAPI + Uvicorn (Webサーバー)
- SQLModel (ORM)
- SQLite (DB)
- APScheduler (スケジューラ)
- Playwright (ブラウザ自動化)
- ruff (リンター・フォーマッター)

#### フロントエンド
- Jinja2 (テンプレート)
- htmx (サーバー駆動UI)
- Tailwind CSS + DaisyUI (スタイリング)
- Tailwind CSS standalone CLI (CSSビルド。Node.js/Bun不要)

#### デスクトップ機能
- winotify (Windows通知)
- pystray (トレイ常駐)

### 開発環境
- WSL2 上で開発
- winotify / pystray はWindows API依存のため、WSL上では無効化フラグで切り替え
- Web UI 部分はWSL上で開発・テスト可能
- backend, frontend

### 配布
- PyInstaller で単一exe化
- Playwright のブラウザバイナリは初回起動時にダウンロード
- PC起動時の自動起動はスタートアップフォルダにショートカット配置

### タスクランナー
- taskipy (開発サーバーのホットリロード, Windows向けビルドなど)
