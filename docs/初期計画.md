# 初期計画

## 概要
社内配布用のWindowsアプリケーションを作成する
PC起動かアプリ起動でバックグラウンドで常駐できるタイプのアプリを制作したい
Windowsに通知を送信して動作状況を確認したい

### 技術スタック

#### バックエンド
- Python 3.12+
- uv (パッケージ管理・実行)
- FastAPI + Uvicorn (Webサーバー)
- SQLModel (ORM)
- SQLite (DB)
- APScheduler (スケジューラ)
- Playwright (ブラウザ自動化)
- ruff (リンター・フォーマッター)

#### フロントエンド
- Jinja2 (テンプレート)
- htmx (サーバー駆動UI)
- Tailwind CSS + DaisyUI (スタイリング)
- Bun (CSSビルドのみ)

#### デスクトップ機能
- winotify (Windows通知)
- pystray (トレイ常駐)

### 
- taskipy 開発サーバーのホットリロード, windows 向けのビルドなど
